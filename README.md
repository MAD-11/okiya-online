# 🌸 Окийя — онлайн

Онлайн-версия настольной игры **Окийя** (Okiya) — изящной дуэльной игры в японском стиле. Игроки по очереди выкладывают карточки императорского сада, пытаясь выстроить ряд из 4 своих жетонов, квадрат 2×2 или заблокировать все ходы сопернику.

**[Играть онлайн](https://okiya-online.vercel.app)** (если задеплоено)

---

## ✨ Возможности

- 🎮 **Мультиплеер** — игра с другими людьми по коду комнаты
- 🤖 **Игра с ботом** — три уровня сложности (лёгкий / средний / сложный)
- 🎓 **Обучающий режим** — пошаговый тренажёр для новичков
- 📖 **Правила игры** — встроенные правила с иллюстрациями
- 📊 **Профиль игрока** — статистика, история партий, рейтинг ELO
- 🏆 **Серии игр** — до 3 или 5 побед со сменой цветов после каждого раунда
- 💬 **Чат** — общение с соперником в реальном времени
- 🔒 **Приватные комнаты** — доступ только по коду
- 🎨 **8 скинов камней** — сакура, птица, клён, луна, бамбук, лиса, Фудзи, тории
- 🌗 **Три темы** — светлая, тёмная и автоматическая (по системным настройкам)
- ⌨️ **Клавиатурная навигация** — стрелки + Enter для игры без мыши
- 📱 **PWA** — устанавливается на телефон как приложение
- 🔊 **Звуки** — ходы, победа, поражение, подключение соперника

## 🛠 Технологии

### Клиент
- **React 18** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Socket.IO Client** — realtime
- **vite-plugin-pwa** — PWA, Service Worker, офлайн-режим
- **Web Audio API** — синтезированные звуки

### Сервер
- **Node.js 20/22**
- **Express** + **Socket.IO**
- **TypeScript**
- **Redis** — хранилище игр, Pub/Sub для чата, адаптер Socket.IO
- **Winston** — логирование
- **Zod** — валидация входящих событий
- **async-mutex** — блокировки на комнату

### Инфраструктура
- **Vercel** — деплой клиента
- **Render** — деплой сервера
- **Upstash / Redis Cloud** — managed Redis
- **GitHub Actions** — CI (типы, тесты, сборка)
- **Jest** — тесты сервера

## 🚀 Локальный запуск

### Требования

- **Node.js** 20 или 22
- **npm** 10+
- **Redis** — установленный локально или через Docker

### 1. Клонирование

```bash
git clone https://github.com/MAD-11/okiya-online.git
cd okiya-online
```

### 2. Redis

Через Docker (рекомендуется):

```bash
docker run --name okiya-redis -p 6379:6379 -d redis:7-alpine
```

Или установите Redis нативно и запустите как службу.

### 3. Сервер

```bash
cd server
npm install
npm run dev
```

Сервер запустится на `http://localhost:4000`.

Переменные окружения (создайте `server/.env`):

```env
PORT=4000
REDIS_URL=redis://localhost:6379
ALLOWED_ORIGIN=http://localhost:5173
```

### 4. Клиент

В новом терминале:

```bash
cd client
npm install
npm run dev
```

Откроется `http://localhost:5173`.

Переменные окружения (создайте `client/.env`):

```env
VITE_SERVER_URL=http://localhost:4000
```

## 📊 CI / CD

При каждом пуше или PR в `main` / `stable-version` запускается GitHub Actions:

1. **Server (Node 20)** — типы, тесты с покрытием, Redis service
2. **Server (Node 22)** — то же
3. **Client (Node 20)** — типы, production build
4. **Client (Node 22)** — то же

Все 4 проверки должны быть зелёными перед мержем PR в `stable-version`.

### Деплой

- **Vercel** деплоит клиент после успешного CI (Deployment Checks)
- **Render** деплоит сервер после успешного CI (After CI Checks Pass)

## 🎮 Как играть

**Цель:** выложить 4 своих камня в ряд (горизонталь, вертикаль, диагональ) или квадрат 2×2.

**Ход:**
1. **Первый ход:** можно взять любую фишку с края поля (не из центра 2×2).
2. **Следующие ходы:** нужно взять фишку, у которой совпадает хотя бы один символ (растение **или** явление) с предыдущей взятой фишкой.
3. Взятая фишка заменяется вашим камнем.

**Победа:** 4 в ряд, квадрат 2×2 или блокировка всех ходов соперника.

**Ничья:** доска заполнена, победителя нет.

Полные правила — в игре, кнопка **📖 Правила**.
